⚡ REST API — Send Orders Programmatically

Use this endpoint to push orders from any source — your own app, a browser extension, or a restaurant POS system.

Webhook Endpoint
POST https://your-foodyfix-app.run.app/api/orders/webhook
Request Headers
Content-Type: application/json X-FoodyFix-Key: your-api-key
Request Body (JSON)
{ "source": "swiggy", // swiggy | zomato | ubereats | custom "order_id": "SWG123456", "restaurant": "Healthy Bowl Co.", "items": [ { "name": "Grilled Chicken Bowl", "quantity": 1 }, { "name": "Fresh Lime Soda", "quantity": 2 } ], "total_amount": 450.00, "timestamp": "2025-01-15T19:30:00Z" }
Successful Response
{ "success": true, "order_id": "FF-0001", "analysis": { "calories": 650, "health_grade": "B", "protein_g": 45, "fat_g": 18 } }
